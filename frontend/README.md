# ML + STEM LAB — frontend

React 19 + TypeScript + Vite SPA. Общие инструкции по запуску, тестам и
развёртыванию — в корневом [`README.md`](../README.md).

```bash
pnpm install --frozen-lockfile
pnpm dev          # http://localhost:5173, /api проксируется на :8000
pnpm typecheck
pnpm test
pnpm build
```
