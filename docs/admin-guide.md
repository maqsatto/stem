# Руководство администратора

Интерфейс CMS — на казахском языке. Ниже названия кнопок даны в кавычках, чтобы
их можно было найти на экране.

## 1. Вход

1. Откройте `/login`.
2. Войдите с учётной записью администратора (`admin@mlstem.kz` в демо-базе).
3. После первого входа смените пароль в разделе «Менің аккаунтым» / `/account`.

Администратору доступны пункты меню:

- «Мазмұн каталогы» — общий каталог всего контента;
- «ML алгоритмдері»;
- «STEM құзыреттіліктері»;
- «Сабақтар»;
- «Тапсырмалар»;
- «Жобалар»;
- «Диагностикалар»;
- «Файлдар» — файлы и ссылки;
- «Пайдаланушылар»;
- «Сыныптар» — только просмотр;
- «Аудит журналы» — только чтение.

## 2. Сквозной порядок публикации

Рекомендуемая последовательность, чтобы не было «висящих» связей:

1. Создайте STEM-компетенции (если их ещё нет).
2. Создайте ML-алгоритм.
3. Создайте урок / задание / проект / диагностику и привяжите компетенции.
4. Загрузите файлы и ссылки.
5. Проверьте предпросмотр.
6. Нажмите «Жариялау» (опубликовать).
7. Проверьте материал в публичном каталоге и на телефоне.

Статусы:

| Статус | Значение |
|---|---|
| «Жоба» | черновик, не виден ученикам (не путать с «жоба» = проект) |
| «Жарияланған» | опубликован |
| «Мұрағат» | архив, скрыт из каталога |

Опубликованный материал нельзя удалить: API вернёт `409 archive_instead`.
Переведите его в «Мұрағат» и сохраните. Черновик, который уже назначен классу,
тоже нельзя удалить.

## 3. ML-алгоритмы

Раздел «ML алгоритмдері» → «Жаңа алгоритм».

Поля:

- название на казахском и (необязательно) английском;
- slug — можно оставить пустым, сгенерируется из названия;
- краткое описание для карточки;
- полный текст в HTML-редакторе;
- обложка — HTTPS-ссылка или путь `/uploads/...`;
- порядок сортировки;
- «Демо-контент» — снимайте галочку только после утверждения материала;
- статус.

«Алдын ала қарау» открывает публичную страницу, если материал опубликован.
Удалить алгоритм можно только пока он черновик и на него не ссылаются уроки,
задания или проекты.

## 4. STEM-компетенции

Раздел «STEM құзыреттіліктері». Для каждой компетенции задаются:

- название и описание;
- индикаторы (список);
- критерии уровней «Төмен» / «Орташа» / «Жоғары»;
- порядок сортировки;
- статус и признак демо.

Диагностика привязывает вопросы к компетенциям, а отчёты считают проценты и
разницу pre/post по каждой компетенции. Поэтому названия и критерии должны
быть утверждены методистом до публикации.

## 5. Уроки

Раздел «Сабақтар» → «Жаңа сабақ».

Заполните название, алгоритм, порядок, длительность, краткое описание, цель,
HTML-содержание, вопрос рефлексии и компетенции. Сохраните и опубликуйте.
Опубликованный урок учитель может назначить классу.

## 6. Задания

Раздел «Тапсырмалар» → «Жаңа тапсырма».

Типы:

- «Бір дұрыс жауап» — один правильный вариант;
- «Бірнеше дұрыс жауап» — несколько правильных;
- «Ашық жауап» — текст;
- «Файл жүктеу»;
- «Сілтеме».

Для закрытых тестов добавьте минимум два варианта и отметьте правильные.
Правильные ответы хранятся на сервере и не отдаются ученику, пока не включён
показ ответов после сдачи. Закрытые тесты проверяются автоматически.

Дополнительно задаются максимальный балл, лимит попыток, рубрика, компетенции
и флаг «показывать правильные ответы после сдачи».

## 7. Проекты

Раздел «Жобалар» → «Жаңа жоба».

Поля: название, алгоритм, краткое описание, проблема, цель, HTML-описание,
шаги, материалы, инструменты, ожидаемый результат, рубрика и компетенции.
Проект оценивает учитель по рубрике после сдачи ученика.

## 8. Диагностики

Раздел «Диагностикалар» → «Жаңа диагностика».

Виды: pre-test, post-test, тест. Для каждого вопроса:

- тип (один / несколько / открытый);
- текст (можно HTML);
- балл;
- компетенция;
- варианты и правильные ответы для закрытых вопросов.

Важно:

- pre/post сравниваются только внутри одного `methodology_key`;
- пороги уровней («Төмен» / «Орташа» / «Жоғары») и веса компетенций
  редактируются в блоке «Scoring конфигурациясы»; пустой вес означает 1.0,
  вес 0 исключает компетенцию из общего балла;
- после появления завершённых попыток структурные изменения (включая пороги и
  веса) возвращают `409` — используйте кнопку «Жаңа нұсқа», чтобы сохранить
  старые результаты;
- ключи ответов ученику не отдаются до условия, заданного в
  `show_correct_answers`.

## 9. Файлы и ссылки

Раздел «Файлдар».

1. Выберите тип материала и конкретную запись — сначала материал должен
   существовать.
2. Выберите аудиторию («Оқушыға», «Мұғалімге», «Барлығына»).
3. Загрузите файл или добавьте HTTPS-ссылку.

Ограничения:

- до 25 МБ (меняется через `MAX_UPLOAD_MB`);
- разрешены `pdf`, `docx`, `pptx`, `csv`, `xlsx`, `ipynb`, `png`, `jpg`,
  `jpeg`, `webp`;
- проверяются MIME и magic bytes; исполняемые файлы отклоняются;
- файлы с аудиторией «Мұғалімге» не видны ученикам даже по прямому URL.

Для ссылки нужны название и HTTPS URL. Ссылка на Colab/Google Drive
добавляется именно так.

## 10. Пользователи

Раздел «Пайдаланушылар».

- Ученики регистрируются сами, если `ALLOW_STUDENT_REGISTRATION=true`.
- Учителей и администраторов приглашает администратор: «Мұғалім / әкімші
  шақыру».
- Временный пароль показывается один раз — передайте его по безопасному каналу.
- «Құпиясөз» сбрасывает пароль и требует смены при следующем входе.
- «Өшіру» / «Қосу» блокирует и разблокирует аккаунт; себя отключить нельзя.
- Смена роли действует сразу для проверок доступа.

## 11. Классы

Раздел «Сыныптар» доступен только для просмотра: администратор видит классы,
учителей, количество учеников и коды вступления. Создание, архивирование и
назначения выполняет учитель в своём кабинете.

## 12. Аудит

«Аудит журналы» — только чтение. Фиксируются публикации, изменения
пользователей, оценки, загрузки и другие действия. Журнал не редактируется
через API.

## 13. Демо-контент и чек-лист публикации

Все seed-материалы помечены «Демо». Перед публикацией реального материала:

- [ ] текст и критерии проверены методистом;
- [ ] источники и ссылки открываются;
- [ ] правильные ответы и баллы соответствуют ключу;
- [ ] файлы доступны нужной аудитории, teacher-only файлы скрыты от учеников;
- [ ] материал корректно выглядит на телефоне;
- [ ] снята галочка «Демо-контент»;
- [ ] материал опубликован и проверен в публичном каталоге.

## 14. Типовые ошибки

| Сообщение / код | Что делать |
|---|---|
| `409 archive_instead` | материал опубликован — архивируйте, а не удаляйте |
| `409 content_in_use` | на запись ссылаются другие материалы — сначала уберите связи |
| `409 assessment_has_attempts` | создайте новую версию диагностики |
| `422 invalid_file_type` / `mime_mismatch` | проверьте расширение, MIME и содержимое файла |
| `413 file_too_large` | уменьшите файл или измените `MAX_UPLOAD_MB` |
| `403 forbidden` | у аккаунта нет роли/владельца для действия |
